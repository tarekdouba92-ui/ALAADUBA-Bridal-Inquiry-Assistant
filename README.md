# ALAADUBA Bridal Inquiry Assistant

A practical Python project built to help manage bridal inquiries for ALAADUBA.

## Project Purpose

This assistant is designed to support the bridal inquiry workflow by collecting client details, generating WhatsApp-style replies, saving client information, viewing saved clients, searching for clients, updating client status, adding client notes, viewing full client profiles, exporting profiles, and editing saved client details.

This is a learning project and an early prototype. All client data used in this repository is fictional/sample data.

## Current Version

Version 1.0 - Python terminal version.

## Features

- Create a new bridal inquiry
- Collect client name, phone, country, dress type, wedding date, and language
- Choose inquiry type:
  - New bridal inquiry
  - Price request
  - Appointment request
- Generate a WhatsApp-style reply
- Save the generated reply to a text file
- Save client data to a CSV file
- View saved clients
- Search clients by name or phone number
- Automatically assign inquiry status
- Update client status
- Add client notes with timestamps
- View full client profile
- Export client profile to a text file
- Edit existing client details
